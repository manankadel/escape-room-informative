# THE ARCHIVE — Escape Room (BabylonJS)

A website disguised as a game. 6 informative blocks are hidden as 3D objects in a BabylonJS escape room.

**Stack:** Vite + TypeScript + BabylonJS 7 + Tailwind

## Hidden Blocks (Informative)
1. **Desk Drawer** → About / Who we are
2. **Glowing Book** → Services
3. **Crooked Painting** → Selected Work
4. **Clock** → Process (code: 2025)
5. **Laptop** → Contact
6. **Safe** → Manifesto (code: 0420)

Find all 6 to unlock the exit door.

## Dev
```bash
pnpm install
pnpm run dev
pnpm run build
```
